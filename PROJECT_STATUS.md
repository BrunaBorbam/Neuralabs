## 🎮 COMO CONTINUAR EM OUTRO PC

### Passo 1: Clonar repositório
```bash
git clone https://github.com/BrunaBorbam/Neuralabs.git
cd Neuralabs
```

### Passo 2: Instalar dependências
```bash
npm install
```

### Passo 3: Setup de ambiente
```bash
# Copie .env.local com:
NEXT_PUBLIC_DISCORD_WEBHOOK=seu_webhook_aqui
NEXT_PUBLIC_GA_ID=seu_ga_id_aqui
```

### Passo 4: Rodar localmente
```bash
npm run dev
# http://localhost:3000
```

### Passo 5: Fazer mudanças
```bash
# Edite os arquivos
# Teste localmente
# Commit e push
git add .
git commit -m "Sua mensagem"
git push
```

**Vercel faz deploy automático!** (2-3 min)
